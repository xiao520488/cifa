# 怎么导入自己的词表（200 个专业词）

## 一、在浏览器里导（推荐，1 分钟）

1. 打开 http://127.0.0.1:5173
2. 点右上角头像 → **我的** → 滚到「词库」→ 点 **导入**
3. 把 200 行词表粘进输入框（一行一个词）
4. 下面会实时显示「可导入 N 个词」；有问题的行会逐行报「第 X 行：原因」，改完再导
5. 点 **导入 N 个词** → 自动切到「我的词库」，从第 1 批开始学

只会替换「我的词库」这一本，内置的高中/四级/六级/考研不动，各自的进度也不动。

## 二、一行长什么样

三种写法都认，音标可以没有：

```
abdomen, /ˈæbdəmən/, n. 腹部
aneurysm  /ˈænjərɪzəm/  n. 动脉瘤
myocardial,/ˌmaɪəˈkɑːdiəl/,adj. 心肌的;n. 心肌
```

- 分隔：逗号或空格/制表符都行（留空格的写法里，`/…/` 那一段会被认成音标）
- 义项：ASCII `;` 或 `|` 分隔；中文 `；` 只分隔同一个义项里的近义词
- 自动跳过：表头（`word,phonetic,meaning`）、空行、`#` 开头的注释
- 会拒收：不是英文单词、释义里没有中文、重复词（库内自动去重）

专业词尤其注意：从 PDF 复制常带**智能引号/全角空格/不可见字符**，这类行会报错，把那几个词手工重敲一遍即可。

## 三、几个要知道的

- **每批 5 个**是默认值，200 词 = 40 批；「我的 → 每批单词数」可改 8/10/15/20。
- **进度存在这台浏览器里**（localStorage）。换浏览器、清站点数据、无痕窗口都会丢，原始 txt 自己留一份。
- 重新导入会**整本替换**「我的词库」，旧那本的已学记录还在但词对不上了；想换词表建议先删旧的再导（我的 → 词库 → 删除）。
- 删除「我的词库」会连它的学习进度一起删，内置词库不受影响。

## 四、直接改 JSON 可以吗？

不建议。内置四本 `src/data/*.json` 是脚本生成的（见 `docs/VOCAB_DATA.md`），手改后要同步改 `src/data/books.json` 里的词数，否则「学习阶段」显示的数字会和实际不一致。你自己的词表走导入就行——数据结构和内置词库完全一样，只是不进版本库。

如果确实要固化成内置阶段（比如做「医学英语」第五本），告诉我，我加一本并接到阶段选择里。
