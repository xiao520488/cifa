# 调度策略原始需求（保存于 2026-11-24）

> 这是用户给出的完整计划原文（只做排版整理，规则一条未改），作为实现与验收的**唯一需求来源**。
> 对应的技术契约见 `SCHEDULER_SPEC.md`，用户可见文案见 `STRATEGY_GUIDE.md`。

## 定位

「背单词 APP 学习调度策略 Agent」。设计并实现一套完整的单词学习与复习调度模块，覆盖：自适应新词量、即时复习、短期复习批次、长期复习节点、逾期池、日历系统、用户自定义新词数。

核心原则：复习永远优先于新词；向下调整快、向上调整慢；停掉的新词不补；逾期只装复习词，不装新词；避免批次无限膨胀和用户崩溃。

## 一、核心概念与数据结构

1. `userDailyGoal`：用户自定义每日新词目标，冷启动默认 20，可随时修改。
2. `maxLimit`：算法允许的最高新词量，默认等于 `userDailyGoal`，用户可单独设上限。
3. `currentLimit`：自适应算法的当前基线新词量，初始等于 `userDailyGoal`。
4. `newWordLimit`：当天实际新词量，由自适应规则算出，范围 `[0, maxLimit]`。
5. 学习日边界：以凌晨 4 点为界，4 点前算前一天，4 点后算新一天。日历、到期、完成率、连续优秀天数均按此边界计算。
6. 短期复习批次：1 天前、2 天前、6 天前、15 天前四个滚动批次。
7. 长期复习节点：30 天、90 天、180 天、360 天，按周/月批量处理，不按天精确到期。
8. 即时复习：新词学习过程中累计满 10 个触发一次当场复习，不进入正式批次统计。
9. 逾期池：只装「到期未完成的复习词」，不装未背的新词。
10. 未学新词池：存放尚未学习的新词，支持按词表顺序或词频抽取，默认按词表顺序。
11. 归档词库：360 天节点完成后归档，不进自动调度，支持手动抽查。

## 二、复习卡片 UI 与作答口径

1. 正式复习卡片：正面只显示单词 + 音标，中文默认遮蔽；底部三键「认识/模糊/不认识」；上方有显示/关闭中文切换；用户可自定义默认显示中文或不显示英文。
2. 作答评分：认识 = 1，模糊 = 0.5，不认识 = 0。
3. 调度动作：
   - 认识 → 进入下一间隔；
   - 模糊 → 间隔缩短或原地重复（如 6 天批次模糊后打回 2 天或原地再出现一次）；
   - 不认识 → 打回 1 天批次或错词本，重新走短周期。
4. 答错后立即重试答对，不计入正确率拉升。
5. 复习完成率分母 = 当天到期总数，不是用户点开始后的数。

## 三、自适应新词量规则

每天结算时按顺序执行：

1. 计算加权近期正确率 `recentAcc = 0.7 × 近3天加权正确率 + 0.3 × 历史累计正确率`。近 3 天按天加权：今天 0.5、昨天 0.3、前天 0.2。
2. 计算 `completionRate = 当天已完成复习数 / 当天到期复习总数`；无到期复习视为 1。
3. 规则：
   - `completionRate < 0.90`：不得增加新词，`consecutiveGoodDays` 清零；若 `< 0.80`，`newWordLimit = round(currentLimit × 0.8)`。
   - `recentAcc < 0.70`：`newWordLimit = 0`，进入恢复期，`consecutiveGoodDays = 0`。
   - `0.70 ≤ recentAcc < 0.80`：`newWordLimit = round(currentLimit × 0.75)`，`consecutiveGoodDays = 0`。
   - `0.80 ≤ recentAcc < 0.90`：`newWordLimit = currentLimit`，`consecutiveGoodDays = 0`。
   - `recentAcc ≥ 0.90`：`consecutiveGoodDays += 1`；只有连续 3 天 `recentAcc ≥ 0.90` 且 `completionRate ≥ 0.95`，才允许增量：`newWordLimit = min(maxLimit, currentLimit + 5)`，增量后 `consecutiveGoodDays` 重置为 0；未满 3 天维持 `currentLimit`。
4. 所有结果限制在 `[0, maxLimit]`。
5. 用户手动强制改新词量只影响当天实际执行，不改变 `currentLimit` 基线。
6. 当天新词没背完：不补、不进逾期池、不滚入次日；未学新词回到未学新词池，按正常流程抽取。
7. 逾期池 ≥ 30 词：日历和新词页面提醒「逾期较多，建议先清一部分」，不强制减新词；≥ 50 词：强制暂停新词，直到降到 50 以下。

## 四、即时复习规则

1. 每累计 10 个新词触发一次即时复习；若单批新词数 > 10，则该批结束立即复习该批；若单批 < 10，跨批累计到 ≥ 10 时触发。即时复习组大小按累计结果走，不拆碎用户批次。
2. 即时复习卡片用「认识/不认识」两键；不认识的放回本组队列末尾，同一词最多循环 3 次；3 次仍不认识 → 标记 `hardWord`，放过，进入明天 1 天正式批次。
3. 即时复习不进入 1/2/6/15 天正式批次，不纳入 `recentAcc` 和 `completionRate`。
4. 即时复习数据单独记录为 `immediateReviewStats`，可作为辅助信号：若平均循环次数普遍 ≥ 2，当天结算时轻微下调新词量或提示。
5. 允许用户跳过即时复习，标记 `skippedImmediate`，这些词明天 1 天批次优先出现，不强制卡流程。
6. 即时复习中途退出不算复习债务，不补不欠。

## 五、短期复习批次规则

1. 四个滚动批次：1 天前、2 天前、6 天前、15 天前，各批次按当天学习日边界计算。
2. 15 天批次支持快速筛查：能回忆的快速过，回忆不出的进错词本/短期循环，不必平均用力。
3. 逾期词的下次间隔按实际复习时间重新计算，不按原计划日期。
4. 逾期超过 7 天仍未复习的词：按词逐个判断，移出逾期池，归入未学新词池，不插队，保留 `relearned` 标记，调度上当新词处理。

## 六、长期复习节点规则

1. 节点：30 天、90 天、180 天、360 天，360 天为最后节点，完成后归档为长期记忆库。
2. 所有词都进长期批次，但按周/月批量处理：30 天批次每周日统一复习过去 7 天内满 30 天的词；90 天批次每月 1 号统一复习过去 30 天内满 90 天的词；180/360 天同理按月批量。
3. 长期批次单独统计，不进入 `recentAcc` 和 `completionRate`，不影响每日新词量决策。
4. 长期批次以快速筛查为主：能秒反应就过，犹豫或错的进错词本/短期循环。
5. 长期批次答错：打回短期循环，重置为需重学状态，重新走 1 天 → 2 天 → 6 天 → 15 天，不继续按 30/90/180 走。
6. 归档词库支持手动抽查，不进自动调度。

## 七、逾期池规则

1. 逾期池只装「到期未完成的复习词」，不装新词；未学新词池和逾期池完全分开，互不抵扣。
2. 当天正常到期复习必须完成或达到完成率门槛，达标后才给新词；复习没达标 → 当天新词量 = 0 或减量。
3. 新词背完后，系统提示逾期池：「你有以下逾期复习未完成：11月20日批次20词、11月18日批次15词……」用户自行选择是否清、清哪一批。不选则保留，不强制。
4. 逾期池按逾期天数从短到长排列，标注每批词数和逾期天数。
5. 每日消化上限只作建议提示（如「建议每天不超过 30 词」），不硬卡。
6. 逾期池 ≥ 30 词提醒，≥ 50 词强制暂停新词。
7. 断签多天回来：不一次性堆到第一天；每天按建议上限清逾期池；新词暂停直到逾期池低于 50；`consecutiveGoodDays` 清零重新积累。

## 八、日历系统

1. 每天显示三块：
   - A. 今日复习批次：列出今天到期的短期批次，标明来源日期和词数，例如「1 天前（11月23日）：20 词；2 天前（11月22日）：20 词；6 天前（11月18日）：20 词；15 天前（11月9日）：20 词；合计 80 词」。
   - B. 今日新词：显示计划值 `newWordLimit` 和用户目标 `userDailyGoal`；若 `newWordLimit < userDailyGoal`，显示原因提示，如「因近期正确率 X%，今日新词调整为 Y 个」。
   - C. 长期批次：单独一栏，显示「本周日：30 天批次复习，预计 20 词」「12月1日：90 天批次复习，预计 20 词」等。
2. 日历至少支持查看今天 + 未来 7 天，方便预判负荷。
3. 复习批次显示「来源日期 + 词数」。
4. 当天复习没做完，日历标「逾期 X 词」，逾期词不自动滚入次日总量，只在日历提示。
5. 日历显示计划值，旁边小字显示实际完成值。
6. 即时复习不进日历。
7. 日历数据来源为每天结算生成的 `dailyPlan` 快照，不实时重算历史。
